# Icaza Live — Project Guidelines

## Visual language

- Use premium, original, real iconography throughout the platform.
- Prefer purposeful branded or professionally designed icon assets over generic symbols, emoji, text glyphs, or improvised placeholder icons.
- Keep icon style, stroke/fill treatment, sizing, and optical alignment consistent within each user flow.
- When a new feature needs an icon, choose or create an asset that communicates the action clearly and respects the Icaza Live blue-and-green visual identity.
